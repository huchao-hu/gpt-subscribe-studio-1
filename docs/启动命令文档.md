# 第一次启动与以后启动

使用 Windows PowerShell，按下面的顺序逐段执行。第一次需要安装依赖，以后不需要重复安装。

如果你的代理需要经过 Clash，先打开 Clash，并保持 HTTP / Mixed 端口可用（本机当前为 `7897`）。普通代理不需要这一步，以下启动命令均不变。

[start-backend.cmd](../start-backend.cmd) 已内置开发配置，不需要手动输入路径环境变量。默认使用模拟适配器（`GSS_USE_FAKE=1`），已设置的业务环境变量优先。真实联调可先执行 `$env:GSS_USE_FAKE = '0'`，再启动脚本。`/pay-protocol` 不受模拟开关保护，不要用它做模拟付款。

## 一、第一次启动

### 第 1 步：打开终端一，安装依赖

```powershell
Set-Location 'G:\aa\kaiyuanxinagmu\gpt-subscribe-studio-1'

python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r .\deploy\server\requirements.txt
npm.cmd install --prefix .tmp/sentinel-node --no-save --package-lock=false undici@6
npm.cmd --prefix apps/web ci
```

以上每条命令成功后再执行下一条。

### 第 2 步：仍在终端一，启动后端

```powershell
Set-Location 'G:\aa\kaiyuanxinagmu\gpt-subscribe-studio-1'
#这个是说明检查 Plus 优惠资格 不是返回固定一个试用而是真正的去调用openai的接口去查询
$env:GSS_USE_FAKE = '0'
.\start-backend.cmd
```

保留终端一运行。

### 第 3 步：新开终端二，启动前端

```powershell
Set-Location 'G:\aa\kaiyuanxinagmu\gpt-subscribe-studio-1'
npm.cmd --prefix apps/web run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开：[http://127.0.0.1:5173](http://127.0.0.1:5173)。

## 二、第二次及以后启动

### 第 1 步：打开终端一，启动后端

```powershell
Set-Location 'G:\aa\kaiyuanxinagmu\gpt-subscribe-studio-1'
#  GSS_USE_FAKE 1 使用模拟适配器；0 使用真实接口
# GSS_ENABLE_PROMO  0 禁止促销模式建单；1 允许使用优惠活动建单
.\start-backend.cmd
```

### 第 2 步：新开终端二，启动前端

```powershell
Set-Location 'G:\aa\kaiyuanxinagmu\gpt-subscribe-studio-1'
npm.cmd --prefix apps/web run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开：[http://127.0.0.1:5173](http://127.0.0.1:5173)。

停止时在两个终端分别按 `Ctrl+C`。热重载或重启会清空内存订单。只有依赖清单变更时才需要重新安装依赖。

调用关系见 [调用流程文档](调用流程文档.md)。

## 三、代理页面配置（保存一次，以后保留）

1. 打开「代理设置」，填写供应商代理地址，点击「解析预览」。SOCKS5 请使用 `socks5://用户名:密码@主机:端口`，无协议的四段地址默认按 HTTP 解析。
2. 打开「启用代理」。只有需要中转的代理才打开「通过本机 Clash 连接」，Clash 地址默认 `http://127.0.0.1:7897`。
3. 点击「保存配置」后「测试连接」。只修改开关时，代理地址留空即可，原账号密码会保留。更换代理时 Clash 开关默认关闭，需要时重新打开。
4. 未配置或停用代理时也能测试出口；此时使用后端电脑的网络路由，系统 VPN / TUN 仍可能影响出口。账单国家不是出口国家，项目没有默认美国代理。

Clash 地址中的「本机」指后端所在电脑。开启中转后 Clash 必须保持运行；失败会报错，不会自动改为直连。测试成功仅代表出口测试网站可达，不代表优惠资格或支付成功。
